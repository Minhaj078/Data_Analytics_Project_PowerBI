# 🏥 Healthcare Analytics Dashboard (Power BI)

## 📌 Project Overview
This Power BI dashboard analyzes healthcare data to track patient admissions, treatment costs, insurance coverage, and recovery trends.

## 🎯 Objectives
- Analyze patient demographics and disease distribution
- Compare treatment cost with insurance coverage
- Monitor monthly admission and recovery trends

## 📊 Key Features
- KPI Cards: Total Patients, Avg Treatment Cost, Insurance Coverage %
- Visuals: Donut Chart, Bar Chart, Line Chart, Table
- Slicers: Gender, Age Group, Disease Type
- DAX Measures & Calculated Columns
- Data cleaning using Power Query

## 🛠 Tools & Technologies
Power BI | DAX | Power Query | Data Modeling
